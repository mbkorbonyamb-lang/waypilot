1. Audit express : le site web suffit

Entrez le site web d’une boutique WooCommerce ou Shopify. WayPilot lit son catalogue public, tel que les clients le voient : sans clé, sans installation, et sans rien modifier.

Ou : importer un CSV, ou connecter la boutique avec une clé

Pour un audit complet (brouillons, stocks, codes-barres) et pour appliquer des corrections.

Sélectionnez un fichier CSV exporté depuis WooCommerce ou préparé dans un tableur. Le fichier reste dans votre navigateur : rien n’est envoyé sur un serveur.

Saisissez le nom de la boutique : WayPilot proposera un préfixe de 3 lettres, modifiable.

Remplace les UGS existantes dans le CSV exporté. Ces remplacements ne sont jamais validés automatiquement. Une ligne sans ID WooCommerce risque d’être importée comme un nouveau produit.

WayPilot ne devine pas les prix, les tailles ou les stocks inconnus. Les corrections proposées doivent être vérifiées avant l’importation.

Espace client

L’audit est gratuit. Les corrections (catalogue corrigé, écriture dans la boutique) sont réservées aux clients WayPilot, avec le code d’accès remis à la commande.

Ou connecter directement votre boutique WooCommerce

Plus besoin d’exporter puis de réimporter un CSV : WayPilot lit le catalogue et, après votre validation, écrit les corrections dans la boutique. Créez une clé dans WooCommerce › Réglages › Avancé › API REST › Ajouter une clé : droits « Lecture » pour un audit, « Lecture/Écriture » pour appliquer des corrections. Les clés restent dans cet onglet : elles ne sont ni enregistrées ni envoyées ailleurs qu’à votre boutique. Révoquez la clé après usage si vous le souhaitez.

Ajouter les variations manquantes

Proposé seulement pour les produits dont les variations utilisent un seul attribut. Le prix est prérempli quand il est connu (prix du parent ou prix commun des autres variations) : vérifiez-le. La quantité en stock est facultative ; laissée vide, WayPilot n’écrit aucune valeur de stock. Les variations validées sont ajoutées au CSV corrigé, ou créées dans la boutique si elle est connectée et que vous cliquez sur « Appliquer ».

3. Examiner et valider les corrections

Les corrections sûres (images répétées, orthographe d’une valeur alignée sur le parent, UGS manquante, texte alternatif des images) peuvent être validées ensemble. Les changements de prix et le remplacement d’une UGS existante restent à examiner un par un. Les décisions ne modifient rien tant que vous n’avez pas téléchargé le CSV ou cliqué sur « Appliquer » (boutique connectée).

Le rapport d’audit client est une page à ouvrir dans le navigateur, puis à imprimer ou enregistrer en PDF (Ctrl+P). Le lien d’aperçu (réservé aux détenteurs du code d’accès) montre les totaux et un exemple, sans la liste des produits ; il expire au bout de 90 jours.

Important : à l’importation, cochez dans WooCommerce l’option de mise à jour des produits existants. Testez d’abord sur une sauvegarde ou quelques produits.

Appliquer sur la boutique

Seules les corrections et les variations validées sont envoyées. Les modifications sont immédiates sur la boutique : faites une sauvegarde avant le premier essai.

Mode lecture seule : aucune modification ne peut être envoyée à la boutique. Le rapport et le CSV restent disponibles. Pour appliquer des corrections, choisissez « Audit et corrections » puis relisez la boutique, avec une clé « Lecture/Écriture ».
