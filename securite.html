Sécurité et données

Mise à jour : 26 octobre 2026.

WayPilot a été conçu pour qu’un commerçant puisse l’essayer sans rien confier. Voici précisément ce qui est lu, ce qui transite, ce qui est conservé et où.

Audit par l’adresse de la boutique

WayPilot lit le catalogue public : l’API publique de WooCommerce (Store API) ou le catalogue que Shopify publie pour chaque boutique. Ce sont les données que la boutique affiche à n’importe quel visiteur : noms, prix, tailles, images.

  • Pas de commandes, pas de clients, pas de brouillons, pas d’accès à l’administration.
  • Les boutiques bloquent cette lecture depuis un autre site. Elle passe donc par un relais WayPilot hébergé chez Cloudflare. Il reçoit l’adresse de la boutique, renvoie le catalogue tel quel et ne le conserve pas.

Audit complet avec une clé API WooCommerce

  • La clé est saisie dans votre navigateur et reste dans l’onglet. Les échanges se font directement entre votre navigateur et votre boutique, sans passer par un serveur WayPilot.
  • La clé disparaît à la fermeture de l’onglet. Vous pouvez la révoquer à tout moment dans WooCommerce › Réglages › Avancé › API REST.
  • Pour un audit, une clé en lecture seule suffit. Une clé en lecture-écriture n’est demandée que pour appliquer des corrections que vous avez acceptées.

Corrections

  • Rien n’est modifié sans votre validation, correction par correction.
  • Chaque modification est notée dans un journal (valeur avant, valeur après) et peut être annulée.
  • Exception : la suppression d’une variation en double est définitive. Nous faisons une sauvegarde de la boutique avant.
  • Sur Shopify, les corrections sont faites par notre équipe, avec les mêmes règles.

Ce qui est conservé

  • Les liens d’aperçu de rapport que nous envoyons : le rapport (nom de la boutique, produits concernés, un exemple) est conservé 90 jours chez Cloudflare, puis supprimé automatiquement. Nous comptons ses ouvertures (nombre, première et dernière date), sans adresse IP ni identifiant.
  • Les clients qui ont un code d’accès : le navigateur garde une empreinte de ce code (stockage local) pour ne pas le redemander. Ce n’est pas un cookie et rien n’est envoyé à un serveur.
  • Vos messages (e-mail, WhatsApp) : ils servent à vous répondre et à préparer un devis.

Rien d’autre : ni catalogue, ni clé, ni compte utilisateur.

Hébergement

  • Site et relais : Cloudflare (Pages et Workers).
  • Copie de secours du site : Hugging Face.
  • Paiement de l’abonnement : Stripe. WayPilot ne voit jamais votre carte bancaire.

Cookies et mesure d’audience

Le site ne dépose aucun cookie. La fréquentation peut être mesurée par Cloudflare Web Analytics, qui compte les visites sans cookie ni identifiant personnel.
